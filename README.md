# Crypto LLM Arena

Multiple LLMs (Claude, GPT, Gemini, Grok) fight to produce the most accurate
trading signals on the top-20 cryptocurrencies. Winners gain decision-making
power in the consensus signal; losers lose it.

> Skeleton README — full documentation is being written in `src/arena/cli.py`'s unit.

See `docs/INTERFACES.md` for the module contracts.
